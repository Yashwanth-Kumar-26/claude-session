Why I built it

To resume a Claude Code session, I had to remember its session ID when I closed it, or search through .claude to find it.

Quick start

  1. Install csessions. The exact command is in the repo README.

  2. Run it.

    csessions

  3. See your recent Claude sessions in a list.

  4. Pick one and resume it.
